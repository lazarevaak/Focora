# **Focora**

**Focora** — это приложение для продуктивности на **macOS**, объединяющее  
**Quick Launcher**, **Task Manager**, **Pomodoro Timer** и **Clipboard Manager** в 4 компактных окон.

Оно создано специально для **разработчиков и работы** — максимально удобно во время работы и кодинга.  

Благодаря **компактному интерфейсу** и **мгновенному вызову сочетанием клавиш**, Focora помогает сохранять фокус, управлять временем и выполнять задачи **без переключения контекста** между окнами и приложениями.

> Название происходит от *focus* и *ora* (“время”) — символ концентрации и управления временем.

## **Основные модули**

### Quick Launcher  
Мгновенно вызывается сочетанием клавиш **⌥ + Space**.  
Позволяет:
- запускать Pomodoro;  
- создавать задачи;
- открыть буфер обмена;
- искать и открывать приложения;  
- делать запросы в ChatGPT и в другие сервисы.  

### Task Manager  
Управляй своими задачами с **тегами, приоритетами и сроками**.  
Функциональность:
- поиск, фильтрация и сортировка;  
- экспорт и импорт календаря задач;  
- синхронизация с системным календарём macOS.  

### Pomodoro Timer  
Фокусируйся на одной конкретной задаче **от 1 до 60 минут**.  
Особенности:
- автоматическое включение режима **«Не беспокоить»**;  
- блокировка отвлекающих приложений по выбору пользователя;   

### Clipboard Manager  
Улучшенный буфер обмена, вызываемый сочетанием **⌘ + ⇧ + V**.  
Возможности:
- мгновенная вставка выбранного элемента;  
- поиск, выбор и удаление записей;  
- быстрый доступ к истории копирования.  

## **Технологии**
- **SwiftUI + AppKit** — гибридная архитектура без Storyboard  
- **Combine** — реактивные обновления между модулями  
- **EventKit** — интеграция с календарём macOS  
- **UserNotifications** — уведомления о завершении Pomodoro  
- **Carbon.HIToolbox** — глобальные горячие клавиши  
- **Accessibility API** — управление и блокировка приложений при Deep Focus
