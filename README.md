**Focora** — это приложение для продуктивности на **macOS**, объединяющее **Quick Launcher**, **Task Manager**, **Pomodoro Timer** и **Clipboard**.

Оно создано специально для разработчиков и создателей — максимально удобно во время работы и кодинга. Благодаря компактному интерфейсу и мгновенному вызову сочетанием клавиш, Focora помогает сохранять фокус, управлять временем и выполнять задачи без переключения контекста между окнами и приложениями.

Название происходит от focus и ora (“время”) — символ концентрации и управления временем.

---

- Quick Launcher
Мгновенно вызывается сочетанием клавиш ⌥ + Space.
Позволяет запускать Pomodoro, создавать задачи, искать приложения.
Делать запросы в ChatGPT и в другие приложения.

- Task Manager
Управляй своими задачами с тегами, приоритетами и сроками.
Поддерживает поиск, фильтрацию, сортировку.
Экспорт и импорт календаря.

- Pomodoro Timer
Фокусируйся на одной определенной задаче от 1 до 60 минут.
Автоматически включает режим «Не беспокоить».
Блокировка отвлекающих приложений по выбору пользователя.

- Clipboard Manager
Улучшенный буфер обмена, вызываемый сочетанием ⌘ + ⇧ + V.
Позволяет быстро вставлять, искать, выбирать и удалять элементы, не покидая текущего окна.
Также делать поиск по элементам.
